# siborg.com — original static website (pre-WordPress archive)

This is a complete copy of the original static HTML website for siborg.com, taken
before the site was converted to WordPress in August 2026.

Contents:

- 13 HTML pages: `index.html`, `company-profile.html`, `products.html`,
  `distributors.html`, `downloads.html`, `publications.html`, `reviews.html`,
  `shareware.html`, `siblin.html`, `lcrreaderpro.html`, `led-test-tweezers.html`,
  `micro-brief.html`, `micro-detail.html`
- `css/`, `js/`, `fonts/`, `images/`, `favicon/` — all original assets
  (Bootstrap 3, Font Awesome, jQuery, carousel)
- `microtec/` — the MicroTec sub-section
- Product manuals and documentation (PDF)

Everything is plain HTML/CSS/JS, so the site can be opened directly from disk:
open `index.html` in a browser. To publish it, upload the whole folder to any web
host — no database, PHP or build step is required.

A copy of the same files also remains on the live server under
`/_prewp_backup_20260808/`.
