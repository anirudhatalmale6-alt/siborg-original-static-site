This archive contains a complete set of MicroTec-4.12 software package
for 2D semiconductor process and device simulation.

A limited capability version of MicroTec is a freeware. You will need
to register to enable full functionality of the package.

The software is supplied "as is" without any accompanying support or
maintenance from Siborg Systems Inc. Under no circumstances will Siborg
assume any responsibility resulted from the use of the software.

MicroTec was used for educational purposes by more than 100 Universities in
28 countries including University of California at Berkeley,
University of Waterloo, Tokyo Institute of Technology, etc.

MicroTec was also used by more than 30 semiconductor companies including
National Semiconductor, Hitachi, Matsushita, General Electric and NTT.

MicroTec limited capability version

You may run MicroTec without registering it. In this case it will run
in a limited mode where you can run any process simulation in a fixed
domain 0.7 by 0.7 microns.

You will also be able to simulate an NMOSFET with 1 um Leff and Tox
of 0.02 um. You cannot change the transistor structure, e.g. location
of electrodes, doping distribution and the domain size, but you can
change the voltages, number of nodes, model parameters etc.

Without the registration, for all other device simulation examples
included in the distribution package you can only plot the simulation
results and edit the input data. Do not try to run these examples
because the doping distribution and geometry of the simulated device
will still be that of the NMOSFET.

MicroTec-4.12 for Windows 95/98/NT/2000/XP installation note

This note describes installation of MicroTec using E-mail.

1.  Run MT412.EXE and follow instructions on the screen
4.  Register you computer using "install_gui_mt.exe" command. Select 
    "Register" and type-in the Registration Code which you may request 
    from microtec@siborg.ca, fill-in all required information and click 
    on "Register". File "inst.pas" will be created which should be E-mailed 
    to microtec@siborg.ca for activation as an attachment by E-mail. 

    We will then register your computer and send you activated "inst.pas" file. 
    Please include the name of the contact person, phone and Fax numbers to 
    facilitate communication should it be required. Keep a copy of the 
    "inst.pas" at all times. Save the received "inst.pas" in the MT412 directory
    and run "install_gui_mt.exe" again, but now select "Install".

    This will complete the installation procedure.
